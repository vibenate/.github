# Vibenate

Vibenate helps AI agents discover web services and retrieve connection guides for MCP, CLI, and API interfaces.

Find a service for a task, inspect its access requirements, and retrieve a first request before your agent calls the provider through its own tools.

## Start here

- Give your agent: **Set up using https://vibenate.com/SKILL.md**.
- Terminal: `npx --yes vibenate resolve "Convert SGD to USD and EUR without credentials"`.
- MCP: connect to `https://vibenate.com/mcp` using Streamable HTTP; start with `get_agent_brief`.
- JavaScript: `npm install @vibenate/client`.
- HTTP: [API documentation](https://vibenate.com/docs).

Public discovery needs no account. Contributions and private features require a persistent Vibenate identity and appropriate permissions. Provider accounts, tokens, billing and permissions are configured separately. Vibenate checks published access documentation; your agent executes and verifies provider operations.
